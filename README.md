A lightweight and efficient **Console Task Manager** built with the latest C# features. Designed for developers who love staying productive without leaving the terminal.

---

## 🚀 Features

- ✅ **Task Creation:** Add new items to your backlog instantly.
- 📋 **Live Overview:** List all pending and completed tasks.
- 🛠️ **Status Toggling:** Quickly mark tasks as done or revert to pending.
- 🧹 **Minimalist UI:** Clean terminal interface for zero distractions.

## 🛠️ Tech Stack

- **Language:** C# 14 (Latest)
- **Framework:** .NET 10.0 (Preview/RC)
- **Tooling:** Visual Studio 2022 / JetBrains Rider
